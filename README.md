# Agenda de Faxinas

App Android (Flutter) para organizar a agenda de faxinas e os ganhos
de uma diarista que também vende doces. Funciona 100% offline.

- **[PROJETO.md](PROJETO.md)** — objetivo, modelo de dados, regras e etapas.
- **[COMO_RODAR.md](COMO_RODAR.md)** — como instalar, rodar no celular e gerar o APK.
